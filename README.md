## Los 7 principios (resumen)

1. **Captura todo. Sintetiza después.** — El cerebro y el agente tienen el mismo bug: si no lo escribís, lo perdés
2. **Capacidad ya no diferencia. Contexto sí.** — Stanford AI Index 2026: top 4 modelos están a 25 puntos de Elo
3. **Silencio del usuario = procesamiento.** — El agente que persigue, pierde
4. **Lo que no se mide, no escala.** — Métrica norte > narrativa cualitativa
5. **IP = contexto curado + método (no código).** — Compartí prompts, protegé data + método
6. **Anti-overengineering: si no se rompió, no lo arregles.** — Stack mínimo viable > ideal teórico
7. **El agente debe mejorar cada semana o es script.** — Inteligencia compuesta = la única ventaja real
